# LeadAIO Launch Plan

Interactive website presenting LeadAIO's rebrand and launch priorities to the team: the eight initiatives, a 16-week roadmap, a week-by-week implementation plan, dependencies, scorecard and open decisions.

- `index.html`: the interactive site (single file, no build step). Open it in a browser or serve it with GitHub Pages.
- `PLAN.md`: the full implementation plan in written form.
- `assets/`: black-and-white background images generated with the OpenAI Images API (`gpt-image-2`) by `scripts/generate-images.py`.
